# Software_MicroProject
 Private Serure Search Engine that will increase the eficiency of ram and storage
# PURPOSE 
This Software Requirements Specification (SRS) defines the functional, non-functional, structural, and research specification for the Privacy-Preserving Inverted Index Search Engine. The system provides localized, offline full-text document indexing and boolean search functionality over raw text corpora while empirically benchmarking two foundational index structures: Hash Maps and Trie (Prefix) Trees. 


# Fundamentals_Functions
● Ingest and preprocess document files (ASCII/UTF-8 encoded plain text and Markdown files). 
● Construct and maintain in-memory Hash Map and Trie inverted index structures. 
● Execute single-keyword, multi-keyword, and boolean constraint queries. 
● Compute relative TF-IDF scores for query matches and display ranked search results. 
● Execute automated performance micro-benchmarks and output timing and memory logs.
